## Task 13: Odd even checker with JS

This task demonstrates how to:
- create a function in JavaScript
- check whether a number is eve nor odd
- print the result to the browser console

### Files
- [Task13/index.html](Task13/index.html): loads the JavaScript file in the browser
- [Task13/script.js](Task13/script.js): has function to check whether a number is odd or even.

### How it works
- The HTML file includes the external script using a script tag.
- The JavaScript file defines a function to check number is odd or even
- A console log prints the results.
