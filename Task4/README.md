# Task 4 contains css Units, box models, fonts simple exercise
This folder contains a simple HTML/CSS demo that shows a styled image and a button.

## Contents
- index.html: Main web page structure
- style.css: Styling for the layout, image, and button

## What the page does
- Displays a forest image in the center of the page with view port css applied
- Shows a clickable button labeled "Click me" having custom css with color, size and font css
- When the button is clicked, a JavaScript alert box appears with the message "Hello! I am an alert box!"

## How to run it
1. Open the Task4 folder in your browser.
2. Double-click the index.html file, or right-click it and open in your browser.
3. You can also open it from VS Code by using the Live Server extension if you have it installed.

## Notes
- No additional setup is required.
- This is a basic front-end example for practicing HTML, CSS, and a small JavaScript interaction.
